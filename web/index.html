Perfect Dark

PC port, running in your browser.

Gamepads only work over HTTPS. Open instead (accept the certificate warning once).

Tip: for the best full-window view, install this page as an app (in Chrome, Edge or Brave: the install icon in the address bar, or menu → Cast, save and share → Install page as app). Browser fullscreen (F11) shows an exit button when the mouse reaches the top of the screen, which gets in the way of looking up.

Online

Start the game and choose Online Matches in the Perfect Menu to see, create and join matches. Up to 4 players per match, plus bots. You can leave and rejoin within a minute and keep your score.

Saves

Agents are saved to the Game Pak, which is kept in this browser and saved as you play. Back them up to a file to move them to another browser or computer, or to keep them safe if this site's data is cleared. The http:// and https:// addresses keep separate saves.
